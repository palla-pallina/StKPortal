Batch Baptism Process
1. User submits form and required documents
2. Admin confirms and accepts the baptism reservation
3. Admin sets date for rehearsal
4. User accepts the set date for rehearsal
5. User visits the parish for the scheduled rehearsal
6. Admin notifies the user of donation minimum 500 for baptism
7. User either sets donation as onsite or gcash
8. Admin sets the rehearsal as 'done' and reminds user of the set date for the baptism
9. User visits the parish for the scheduled Baptism
10. User waits for the Baptism certificate to be released
